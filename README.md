# Malfu Combat Animation — Hand-Keyed Swings for Better Combat

Malfu Combat Animation 9minecraft Resource Pack adds custom attack animations and modified weapon attributes for Better Combat. It replaces default attack motions with fresh battle moves across many melee weapon types. The pack works alongside its companion data pack to link every swing to the correct weapon category. It fits right into custom modpacks and gives close-quarters battles a distinct visual style.

Adds custom attack motions for many weapon classes in Better Combat.

## What this build is

An unofficial rebuild of **Malfu**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Keeping a pack alive across releases is not a copy-paste job: each Minecraft version bumps the pack format and shuffles texture and model paths, so the tree gets re-mapped and every asset re-checked against the version it is built for. Anything the new release dropped is rebuilt rather than left pointing at a path that no longer exists.
